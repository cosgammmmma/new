## 🔴 **优先级1：7分30秒后己方小禁区优先策略** 🆕

### **触发条件：**
- `GlobalVar.Paishu >= 4500` （7分30秒后）
- 非堵球门状态
- **己方**小禁区内有未得分的球
- **无分数要求！** 无论分数高低都会触发

### **执行措施：**
- **选球：** 选择小禁区内距离最近的球（两条鱼各选一个）
- **动作：** `the_warrior2()` - 将球推进框
- **无球时：** `chanqiuqubahaizi()` - 铲球策略

### **调试信息：**
- "7分30秒后小禁区球数"
- "7分30秒后优先处理小禁区球"
- "7分30秒后0号鱼将小禁区球推进框"

## 🟠 **优先级2：全局小禁区高分策略**

### **触发条件：**
- 小禁区内（x < -952，|z| < 508）所有球的总分 > 9
- **注意：** 包括已得分的球

### **计分规则：**
- 0-2号球：3分
- 7-8号球：2分  
- 3-6号球：1分

### **执行措施：**
1. **选球：** 选择小禁区内距离最近的球（两条鱼各选一个）
2. **动作：** `the_warrior2()` - 将球推进框内
3. **无球时：** `chanqiuqubahaizi()` - 铲球策略
4. **速度优化：** 如果角速度<0.08且速度<20，VCode=12加速
5. **执行后：** 直接返回，不执行后续策略

### **调试信息：**
- "小禁区内球总分"
- "小禁区球总分>9，两鱼将球运进框"
- "0号鱼将小禁区球推进框" / "1号鱼将小禁区球推进框"

### **3.1 特殊期策略（3002-3080拍，5:00-5:08）**

#### **触发条件：**
- `num2 >= 3002 && num2 <= 3080`
- 非堵球门状态

#### **执行措施：**
根据己方半场（x < 0）球的总分决定：

**情况A：己方半场分数 <= 6**
- **0号鱼：** `ChoseBall_OppHalf()` - 选择对方半场的球
- **1号鱼：** `ChoseBall_OppHalf()` - 选择对方半场的球
- **目的：** 两条鱼都去对方半场抢球

**情况B：6 < 己方半场分数 < 9**
- **0号鱼：** `ChoseBall_OppHalf()` - 选择对方半场的球
- **1号鱼：** `ChoseBall20()` - 正常选球
- **目的：** 一条鱼去对方半场，一条鱼正常

**情况C：己方半场分数 >= 9**
- **0号鱼：** `ChoseBall20()` - 正常选球
- **1号鱼：** `ChoseBall20()` - 正常选球
- **目的：** 己方半场球够多，正常打

---

### **3.2 普通阶段策略**

#### **选球：**
- `ChoseBall20()` - 正常选球策略

#### **执行措施（0号鱼）：**

**情况1：球在角落**
- **条件：** `whether_CornerChoseBall() == 1` 或处于角落铲球阶段
- **动作：** `chosecornerInterfereBall(0, 1)` - 上方角落铲球

**情况2：球在角落**
- **条件：** `whether_CornerChoseBall() == 2` 或处于角落铲球阶段
- **动作：** `chosecornerInterfereBall(0, 0)` - 下方角落铲球

**情况3：2号球特殊处理（前100拍）**
- **条件：** 选中2号球 且 鱼头在球后面 且 距离>150 且 num2<100
- **动作：** `Position()` - 先定位到球附近

**情况4：普通运球**
- **动作：** `Dribblehometest1()` - 运球回家

**情况5：无球可选**
- **动作：** `chanqiuqubahaizi()` - 铲球策略

#### **执行措施（1号鱼）：**
同0号鱼，但处理0号球和上方角落

### **5.2 原Final阶段策略（已被优先级1替代）**

**注意：** 7分30秒后的小禁区优先策略已移至优先级1，无论分数高低都会触发。

以下是原来的判断逻辑（仅供参考）：

#### **判断逻辑：**
```csharp
// 遍历所有9个球
for (int frameIdx = 0; frameIdx < 9; frameIdx++)
{
    // 判断条件1：球在己方小禁区内
    bool inSmallArea = GlobalVar.BaAction.whether_in_myforbiddenareasmall(
        球的X坐标, 球的Z坐标
    );
    // 判断条件2：球未得分
    bool notScored = GlobalVar.leftScore[frameIdx] != 1;
    
    // 两个条件都满足，计数+1
    if (inSmallArea && notScored)
    {
        ballsInSmallArea++;
    }
}

// 如果计数 > 0，说明有未得分的球在己方小禁区
if (ballsInSmallArea > 0)
{
    // 触发策略
}
```

#### **判断细节：**

**条件1：球在己方小禁区内**
- 使用函数：`whether_in_myforbiddenareasmall(x, z)`
- 判断标准：`x < -952 && |z| < 508`
- 说明：球的X坐标小于-952（己方半场），且Z坐标绝对值小于508

**条件2：球未得分**
- 使用变量：`GlobalVar.leftScore[ballIdx]`
- 判断标准：`leftScore[ballIdx] != 1`
- 说明：
  - `leftScore[ballIdx] == 0`：球未得分
  - `leftScore[ballIdx] == 1`：球已得分（己方或对方）

**触发条件：**
- 当 `ballsInSmallArea > 0` 时，说明至少有1个球满足上述两个条件
- 此时触发7分30秒后小禁区优先策略

#### **执行措施：**

**步骤1：检查己方小禁区**
- 计算**己方**小禁区内（x < -952，|z| < 508）未得分球的数量

**步骤2：如果己方小禁区有球**
- **选球：** 选择距离最近的球（两条鱼各选一个）
- **动作：** `the_warrior2()` - 将球推进框
- **无球时：** `chanqiuqubahaizi()` - 铲球

**步骤3：如果己方小禁区无球，执行原策略**
- 跳转到 4.3 或 4.4

#### **调试信息：**
- "7分30秒后小禁区球数"
- "7分30秒后优先处理小禁区球"
- "7分30秒后0号鱼将小禁区球推进框"
- "7分30秒后小禁区无球，执行原策略"

- **条件：** 对方1号鱼朝向 -175° ~ -140°
